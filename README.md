# Vision

Vision is a standalone AI Design Director Skill for product interface and experience work. It helps the AI already used by a customer understand a product, make contextual design decisions, work within the user's scope, and report evidence honestly.

- **Version:** 1.0.0
- **Former name:** Dirro
- **Price:** Free
- **Signup:** None
- **License:** MIT, scoped to this standalone Vision Skill package

## Public release

Vision V1 is available as a standalone Agent Skill. It works without an MCP server, proprietary hosted AI, or another director. The customer's host supplies whatever project tools, models, and permissions are actually available.

The MIT license applies only to the files within this Vision Skill package. It does not apply to the existing Dirro MCP, other source code, or any other files in the enclosing repository.

The Skill uses progressive references for Creative Philosophy, Experience Intelligence, Component Intelligence, Anti-AI-Slop, Asset Intelligence, and Visual Judgment. It preserves Quick, Focused, Full, and NO_CHANGE. Its Farvo, Habis, and Swapme examples are contextual specification fixtures, not claims that those products were inspected or permission to edit their repositories.

Vision V1 is icons-first. No exact reviewed, eligible icon records were found in the source project, so the package includes no icon files and makes no pre-cleared asset or license recommendation. Use an existing approved project icon family or verify the exact new source and terms before recommending use. Vision does not generate photography, illustrations, mascots, logos, or video.
