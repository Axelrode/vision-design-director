# Asset Intelligence — icons first

Use this discipline when an icon is missing, unclear, inconsistent, or has uncertain provenance. Vision V1's asset scope is icons only.

## Prefer existing approved assets

Inspect the relevant product's current icon family, usage, meaning, size, weight, state, accessibility, and source only through authorized host tools. If an icon is clear, coherent, licensed, and approved, prefer **KEEP_EXISTING**. A general request to modernize the UI does not authorize replacement of an icon family, mascot, logo, photograph, illustration, or brand system.

Use icons when they improve recognition, scanning, action choice, state understanding, or approved identity. Prefer clear text when a glyph is ambiguous. An icon-only control needs an accessible name and real button or link behavior. State, errors, selection, and status must not rely on a tiny symbol or color alone. An icon never establishes an authoritative business or transaction state.

## V1 catalog boundary

The source project has an empty icon catalog and no exact reviewed, eligible asset records. Vision therefore has **no pre-cleared icon candidates** to return. Do not invent catalog IDs, asset URLs, hashes, package versions, license claims, or say an icon was installed. No reviewed match is an honest outcome. The Skill package includes no third-party icon files.

If a new source is considered using the host's actual, authorized research capabilities, verify the exact publisher and asset identity, release or package version, applicable license text, intended commercial use, modification and distribution terms, notice-retention obligations, visible attribution separately, review date, and safe technical handling. If any material term or identity is unknown, label it and withhold a definitive use recommendation. Preserve required notices.

The prior specification names these as **research starting points**, not as per-asset approvals or eligible Vision catalog entries:

- [Lucide license](https://lucide.dev/license)
- [Heroicons project](https://heroicons.com/)
- [Phosphor core license](https://github.com/phosphor-icons/core/blob/main/LICENSE)
- [Tabler license](https://tabler.io/license)

Confirm the current official terms and exact icon release at the time of use. An open-source license does not by itself grant trademark rights or remove notice obligations.

## Unsupported categories and safe handling

Do not use this engine to generate or source new photographs, logos, mascots, illustrations, or video. If a requested asset is outside icons, state that this V1 asset guidance does not cover it; the host may have a separate user-authorized workflow, but that is not Vision's V1 catalog.

Treat SVG as structured active content. Do not paste untrusted SVG into raw HTML. Use a trusted, pinned, safely handled asset path and preserve license notices. Do not weaken project content-security controls or introduce a new package without need and authorization.
